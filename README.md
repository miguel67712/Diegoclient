# DIEGO Distribution — Commande Secrétariat

Standalone quote-request mini-site for DIEGO Distribution. Visitors describe
what they need (fûts, hôtesse(s), machine(s)/tireuse(s), gobelets
supplémentaires) with simple +/- counters — no prices shown — and submit.
The site generates a summary as an image and sends it straight to the
secretary's WhatsApp for a personalized quote.

This is a companion site to the main `swift-send-forms` ordering site; it is
kept separate on its own repo/deployment.

## Stack

TanStack Start + React + TypeScript + Tailwind CSS (same stack as the main
site).

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
